# Dashboard hero image

Place the dashboard image here with this exact name:

`yicare-dashboard-hero.jpg`

Recommended size: 2400 x 1350 pixels or larger, in landscape orientation.
The dashboard applies its own dark overlay so the heading and actions remain legible.

# Login background image

Optionally place a login background image here with this exact name:

`yicare-login-background.jpg`

Recommended size: 2000 x 1300 pixels or larger, in landscape orientation.
The login page applies a black overlay so the wide light form stays readable.
